# GameFeel

Bộ tài liệu và công cụ về **game feel** cho game mobile casual / puzzle (Unity).

| Nội dung | Mô tả |
|---|---|
| [game-feel-guide.md](game-feel-guide.md) | Guide chính: nguyên tắc, độ trễ, nút & UI, tween/spring, FX, âm thanh, haptics, chuyển màn & loading, bài học từ game hit, checklist nghiệm thu. Viết để agent và người làm game tuân theo. |
| [feel-demos-study.md](feel-demos-study.md) | Nghiên cứu Feel (More Mountains): từng demo, kiến trúc, công thức cho puzzle, bẫy giá trị mặc định, Nice Vibrations v1.x vs v4, lý do không dùng Feel. |
| [FeedbackKit/](FeedbackKit/README.md) | Hệ thống feedback tự viết trên DOTween (Unity 2022.3+ / Unity 6): `FeedbackPlayer`, 15 feedback, `JuicyButton`, `FeedbackLab`, Inspector riêng. |

**Bắt đầu:** đọc guide mục 0 → chép `FeedbackKit/` vào `Assets/` của game → làm theo `FeedbackKit/README.md`.
